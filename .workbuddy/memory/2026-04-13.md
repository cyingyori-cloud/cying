## 发现产品需求申请对象
- 通过 ListRelatedObjects(NewOpportunityObj) 找到正确 API 名称
- **产品需求申请** 对象 API 名称：`product_requirement_applic__c`
- 关联字段：`project_name__c`（关联到 NewOpportunityObj）

### 产品需求申请关键字段
| 字段 API 名 | 标签 | 类型 |
|---|---|---|
| `_id` | ID | text |
| `name` | 主属性(编号) | auto_number |
| `project_name__c` | 项目名称 | object_reference → NewOpportunityObj |
| `target_power_kw__c` | 目标功率 (kW) | number |
| `target_capacity_kwh__c` | 目标容量 (kWh) | number |
| `backup_power_duration_min__c` | 备电时长 (min) | number |
| `dc_min_voltage__c` | DC 最低电压 | number |
| `dc_max_voltage__c` | DC 最高电压 | number |
| `scene__c` | 场景 | select_one (AIDC/UPS备电 / 工商业储能 / 户储) |
| `wiring_method__c` | 接线方式 | select_one (2线/3线) |
| `cabinet_fire_protection__c` | 机柜消防 | select_one (带/不带) |
| `module_fire_protection__c` | 模组消防 | select_one (带/不带) |
| `special_requirement_remark__c` | 特殊需求/备注 | long_text |
| `life_status` | 生命状态 | select_one |
| `owner` | 负责人 | employee |
